### 课程评价：

这门课程是成为机器学习工程师的最佳起点。即使你已经有基础，课程中深入讲解的许多算法（例如决策树）也能帮助你进一步提升技能。

**特别感谢[吴恩达（Andrew Ng）教授](https://www.andrewng.org/)设计并打造了这门课程。**

    - 使用合适的参数训练智能体之后的最终着陆效果：

    - 基于电影类型收集电影数据库。
